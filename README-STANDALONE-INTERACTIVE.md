## 🔧 Troubleshooting

**Q: No data shows up?**
A: Make sure you're using `index-interactive-standalone.html` (not the regular version)

**Q: Changes don't save?**
A: Check for "✓ Saved" indicator. Don't use incognito mode.

**Q: Can I use on multiple computers?**
A: Data saves to each browser separately. Use CSV export to transfer.

**Q: How do I backup my data?**
A: Click "Export CSV" regularly and keep the files.

**Q: Can I customize the quotes?**
A: Not in the UI, but you can edit the HTML file (search for `QUOTES` array)
